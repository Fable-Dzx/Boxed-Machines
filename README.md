# 盒装机器 (Boxed Machines)

**Minecraft Fabric 模组 | 版本 1.21.11**

将红石机器和生电装置封装进单一方块！放置即自动运行，右键查看产出，自动向相邻容器输出。

## 特性

- **27 种盒装机器** — 覆盖刷怪、动物、资源、植物和特殊农场
- **放下即用** — 无需燃料、无需能量，自动运行
- **GUI + 自动输出** — 右键查看/取出产出，同时自动向相邻箱子/漏斗推送
- **3 级套娃合成** — 基础材料 → 核心组件 → 机器成品，循序渐进

## 合成体系

### 第1级：基础材料
- **机器外壳** = 铁锭×4 + 红石×2 + 黑曜石×2 + 石英
- **红石芯片** = 红石块×4 + 金锭×4 + 钻石

### 第2级：核心组件（27种，每台机器一种）
- **xxx核心** = 机器外壳×2 + 红石芯片 + 特定材料×4

### 第3级：机器成品
- **盒装xxx机** = 对应核心×2 + 机器外壳 + 高级辅助材料

## 构建

```bash
./gradlew build
```

构建产物在 `build/libs/` 目录下。

## 环境要求

- Minecraft 1.21.11
- Fabric Loader >= 0.18.1
- Fabric API >= 0.141.1+1.21.11
- Java 21
