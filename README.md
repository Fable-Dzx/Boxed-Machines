# 盒装机器 Boxed Machines

一个 Fabric 模组（**Minecraft 1.21.11**）：把刷铁机、刷石机、岩浆机、岩浆烤鸡机等生电机器做成**可直接摆放的盒子方块**——放置后自动产出资源，右键一键收取，还能用红石比较器读取储量。

## 安装

1. 安装 [Fabric Loader](https://fabricmc.net/use/)（≥ 0.19.5）并启动一次 1.21.11 客户端
2. 将 `boxedmachines-1.0.0.jar` 放入 `.minecraft/mods/`
3. 安装 [Fabric API](https://modrinth.com/mod/fabric-api)（≥ 0.141.6+1.21.11，版本配套即可）
4. 启动游戏，创造模式物品栏「盒装机器」分组可看到全部物品

## 使用方法

- **放置**：机器放置后立即开始工作，按设定间隔自动产出，内部最多囤 6 组
- **收取**：右键一键收取全部产出（背包满时掉落在身边）
- **比较器**：机器后侧输出 1–15 信号强度 = 内部物品数量
- **拆下**：任意工具/徒手均可拆下（不会损坏）；拆下时内部物品掉落

## 套娃合成（共 3 层，不超过 3 次）

```
铁锭×4 + 红石            → 机械齿轮
机械齿轮×4 + 铜锭×4 + 铁锭 → 盒装机壳
盒装机壳 + 主题材料×8      → 各盒装机器
```

- **机械齿轮**：`铁锭×4 + 红石`（十字形摆放）
- **盒装机壳**：`机械齿轮×4 + 铜锭×4 + 铁锭`（齿轮四角、铜锭四边）
- **各机器**：机壳居中，主料四角、辅料四边（如刷铁机 = 机壳 + 铁锭×4 + 铁栏杆×4）

## 开发

```bash
# 需要 JDK 25 + Gradle 9.7+
gradle build        # 产物在 build/libs/boxedmachines-1.0.0.jar
gradle runClient    # 启动开发客户端（需另装 Fabric API 依赖）
```

- 模组 ID：`boxedmachines`
- 代码包：`net.boxedmachines`
- 技术栈：Fabric API 0.141.6+1.21.11、Yarn 1.21.11+build.6、Java 21 字节码（release 21）
- 所有机器共用 `MachineBlockEntity`（WriteView/ReadView 持久化），调整某台机器的产出/间隔只需改 `ModBlocks.java` 里的 `MachineSpec`
